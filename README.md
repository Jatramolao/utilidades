# utilidades

Herramientas pequeñas y autocontenidas de Juan Tramolao. Cada carpeta es un proyecto
independiente, con su propio README, sus pruebas y su despliegue.

| Proyecto | Qué hace | Estado |
|---|---|---|
| [`nube-palabras/`](nube-palabras/) | Nube de palabras en vivo para clase: lanzas una pregunta, los alumnos responden desde el teléfono y las respuestas se proyectan. Sin cuentas ni datos personales. | ✅ [en producción](https://utilidades-psi.vercel.app) |

## Criterio

Superficie pequeña por defecto: un propósito por carpeta, cero dependencias mientras se pueda,
y nada que haya que mantener para que siga funcionando el año que viene.
